# ⚡ CLAUDEMIRR THEME FOR ZSH!


Welcome to **claudemirr**—a custom, minimalist style, from robbyrussell, or apts to your flow.

## ⬇️ Installation

1. 🌀 **Clone the repository**

   ```sh
   git clone https://github.com/claudemirtech/claudemirr.git
   ```

2. 📁 **Copy the theme file**

   ```sh
   cd claudemirr/
   cp claudemirr.zsh-theme ~/.oh-my-zsh/themes/
   # or you can copy and paste manually
   ```

3. 📝 **Set it in your `.zshrc` configuration file**

   ```sh
   ZSH_THEME="claudemirr"
   ```

4. 🔄 **Reload zsh**

   ```sh
   source ~/.zshrc
   ```
